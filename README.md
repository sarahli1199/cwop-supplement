# CWOP supplementary material

Supplementary material for **Controlling Creator Exposure under Recommendation Feedback** by Wenjing Li, Jiang Rong, Zhenzhe Zheng, and Fan Wu.

## Download

[**Download the supplementary material (ZIP)**](ICDE_CWOP_Supplement.zip?raw=true)

The ZIP contains the supporting PDF, its LaTeX source, and the computational artifact.

## Package contents

| Path inside the ZIP | Contents |
| --- | --- |
| `ICDE_CWOP_Supplement.pdf` | Supporting theory, proofs, and experimental protocols |
| `document/` | Complete LaTeX source for the supplementary document |
| `artifact/` | Experiment code, tests, pinned dependencies, and reproduction instructions |
| `README.txt` | Package overview and document build instructions |
| `MANIFEST_SHA256.json` | Checksums of the delivered files |

## Reproduction

1. Download and extract `ICDE_CWOP_Supplement.zip`.
2. Open `ICDE_CWOP_Supplement.pdf` for the supporting theory and protocols.
3. Follow `artifact/README.txt` for environment setup, public-data downloads, experiment order, and validation commands. Run the experiment commands from `artifact/`.

To build the supplementary document in Overleaf, upload `document/`, select `ICDE_CWOP_Supplement.tex` as the main file, and use XeLaTeX.

## Data and results

Synthetic inputs are generated by the included runners. Public inputs come from [HetRec 2011 Last.fm](https://grouplens.org/datasets/hetrec-2011/) and [KuaiRand-Pure](https://kuairand.com/); download instructions and upstream usage notices are retained in the bundle.

The package contains no datasets, saved numerical results, fitted model or policy arrays, run logs, raw company records, or internal company field names. The supplementary document contains theory and protocols; empirical numerical results are reported in the main paper.
